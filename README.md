# Darts-Club Update 1.5.2

Dieses Update vergrößert das App-Logo, macht die Kopfzeile auf Mobilgeräten besser sichtbar und ergänzt den Copyright-Hinweis.

## Änderungen
- größeres Dart-Logo in Seitenleiste und mobiler Kopfzeile
- Kopfzeile bleibt oben sichtbar
- Copyright-Hinweis: © Marcel Hentschel 2026
- keine Änderungen an Spielern, Punkten oder Kasse

## Installation
1. JSON-Backup in der App erstellen.
2. ZIP entpacken.
3. Dateien ins Hauptverzeichnis des GitHub-Repositories hochladen und bestehende Dateien ersetzen.
4. Commit bestätigen und danach die App neu laden.
