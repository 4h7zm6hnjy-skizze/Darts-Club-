# Darts-Club Update 1.6.0

Dieses Update räumt die Kopfzeile auf und gibt der App einen freundlicheren Dart-Look.

## Enthalten
- obere Kopfzeile entfernt
- Version und Backup-Pfeil in das neue Logo-Kästchen verschoben
- Spieler-Icon unten und in der Seitenleiste auf Dartpfeil geändert
- freundlicheres Farbdesign mit mehr Dart-Charakter
- technische Prüfung der Kernfunktionen (Syntax- und Strukturprüfung)

## Hinweis
Spieler, Papierliste, Champions, Fotos und Kasse bleiben erhalten.
